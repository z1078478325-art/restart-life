张昱辰·重启人生计划 V1.0

1. 解压 ZIP，把 index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png 一起上传到 GitHub 新仓库的根目录。
2. 在仓库 Settings > Pages，选择 Deploy from a branch，main，/(root)，保存。
3. 等 GitHub Pages 发布完成后，用安卓 Chrome 打开发布网址，菜单选择“安装应用”。
4. 所有记录默认保存在当前手机的浏览器本地存储，不上传 GitHub。请在“首页 > 设置与备份”定期导出 JSON 备份，尤其在换机或清理浏览器数据之前。
5. 本应用不能诊断酒精依赖、预测戒断风险或自动提供减酒剂量。几乎每日大量饮酒者应先咨询医生，避免自行突然停酒或快速减量。若减酒或停酒后出现手抖、异常出汗、明显心慌或持续呕吐，请及时就医；如出现抽搐、幻觉、意识混乱，请立即急诊。
6. 运动、饮食和英语内容均为基础参考，按个人情况调整。
